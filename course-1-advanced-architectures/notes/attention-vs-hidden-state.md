# Attention 与 RNN hidden state 的区别

## 共同点

两者都在回答「当前位置该关注哪些信息」，都会为序列中的 token 产出一个上下文相关的表示。

## 信息如何流动

- **RNN hidden state**：第 t 步的 `h_t` 由 `h_{t-1}` 和 `x_t` 递推得到，是一个被反复覆写的
  固定维度向量。距离越远的信息经过越多次非线性变换，越容易被稀释（长程依赖问题）。
- **Self-attention**：每个位置直接与序列中所有位置计算相似度并加权求和，任意两个 token 之间
  的路径长度都是 O(1)，不存在逐步衰减。

## 能否并行

- RNN 必须按时间步串行，`h_t` 依赖 `h_{t-1}`，训练时难以并行。
- Attention 对所有位置同时做矩阵运算，整个序列一次算完，天然适合 GPU 并行。

## 记忆的容量

- hidden state 是固定大小的「瓶颈」，整段历史要压进一个向量。
- attention 不压缩历史，每个位置保留一份表示，通过 Q/K/V 按需读取；多头注意力则允许
  在不同子空间里关注不同关系。

## 代价

RNN 每步 O(1)、整序列 O(n)；self-attention 的打分矩阵是 O(n²)，长序列显存与算力开销明显。
这也是后续各种高效注意力（稀疏、线性、FlashAttention）要解决的问题。

## 一句话

hidden state 是「把过去压缩成一份摘要往下传」，attention 是「保留全部原文，随时按相关性查」。
